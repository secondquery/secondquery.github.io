Account X-ray

A free first look at your Google Ads or Microsoft Advertising account. Drop in a report you can export in a minute and get an instant read on the things that usually matter most. Your file is read by your own browser and never uploaded anywhere.

Run paid search in-house? There are also free Google Ads scripts for n-grams, anomaly alerts and budget pacing.

1

Pull two reports

You don't need to change anything in your account or your usual column views. Build two quick reports, save them, and next month they're one click away. Use the last 90 days if you can (30 at the very least).

Report 1: Campaignsabout 3 minutes, then saved
  1. In Google Ads, open Campaigns, then Insights and reports, then Report editor. (Or type "Report editor" into the search bar at the top.)
  2. Select Custom, then Table.
  3. Drag these into Rows: Campaign, Campaign type, and Day or Week if you'd like the trend charts.
  4. Drag these into Columns:
CostConversionsConv. valueClicksImpr.Search impr. shareSearch lost IS (budget)Search lost IS (rank)
  1. Set the date range (top right) to the last 90 days.
  2. Select Save and call it something like "X-ray: campaigns", then use the download icon and choose .csv.

Shortcut: if you see a Generate report box on the Report editor page, you can paste this instead and check the result has the columns above.

Table of cost, clicks, impressions, conversions, conversion value, search impression share, search lost impression share (budget) and search lost impression share (rank) by campaign, campaign type and week for the last 90 days
Report 2: Search termsabout 2 minutes, then saved
  1. In Report editor, select Custom, then Table again.
  2. Drag Search term and Campaign into Rows (add Search term match type if it's offered).
  3. Drag these into Columns:
CostConversionsConv. valueClicks
  1. Same 90-day date range. Save it as "X-ray: search terms", then download as .csv.
Report 1: Campaignsabout 3 minutes, then saved
  1. In Microsoft Advertising, select Reporting, then Templates from the menu on the left.
  2. Open the Campaign template (under Performance) and select Modify.
  3. Check these metrics are included, adding any that are missing with the + next to Metrics. Add Campaign type as a breakdown, plus Week or Day if you'd like the trend charts.
Campaign nameSpendConversionsRevenueClicksImpressionsImpr. shareImpr. share lost to budgetImpr. share lost to rank
  1. Set the date range (top right) to the last 90 days and select Save.
  2. Select Download and choose .zip (CSV). You can drop the .zip straight in here; the X-ray opens it for you.
Report 2: Search termsabout 2 minutes, then saved
  1. Go to Reporting, then Templates, and open the Search term template. Select Modify.
  2. Check these are included, then set the last 90 days and Save:
Search termSpendConversionsDelivered match typeRevenueClicksCampaign name
  1. Select Download, choose .zip (CSV) and drop the .zip in here.

Pink columns are needed. The rest make the read much sharper, and the X-ray tells you which ones it found.
